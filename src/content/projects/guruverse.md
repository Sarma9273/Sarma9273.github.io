## Why it exists

A conventional portfolio can show project cards without explaining how the systems relate or how they were built. GURUVERSE turns the portfolio into an explorable engineering environment while keeping the primary content static and accessible.

## Architecture

Astro provides the static application and content layer. Feature modules handle navigation, projects and architecture views. Progressive enhancement adds Mission Control, GalaxyEngine, ProjectWorld interactions and grounded GURU-BOT context without making those layers prerequisites for the core content.

## Experience model

Identity → Evidence → Understanding → Exploration → Delivery.

Visitors can start with the person and career story, inspect project evidence and architecture, then move into deeper project worlds and connected systems.

## Engineering boundary

GURUVERSE is deliberately not a private portal, enterprise CRM, heavy WebGL application or fake AI demo. Advanced spatial behaviour is optional; the static page remains the source of truth.
