# Portfolio V4 — Security Intelligence Journey

V4 keeps the working Astro, GitHub Pages, Google Drive blog and Apps Script contact architecture from V3 while replacing the homepage experience with an original immersive design.

## New experience

- Cinematic, skippable portfolio system introduction
- Interactive canvas-based Security Intelligence Core
- Personal career journey rendered as a system log
- Three interactive professional-focus modes
- Horizontally scrollable flagship project storytelling
- Interactive CyberGPT architecture explorer
- Dark-first security visual identity with a calmer light theme
- Reduced-motion support and responsive mobile alternatives
- Existing Drive-powered blog journal retained
- Existing Apps Script contact form retained

## Important integration note

The distributed source keeps the Apps Script URL placeholder because deployment URLs are private project-specific configuration. Before replacing a live repository, preserve the configured value from `src/data/integrations.ts` and paste it into the V4 file.

## Originality

The design uses immersive storytelling principles but does not copy the reference portfolio's 3D avatar, page composition, assets, colour palette, typography or animation sequence. The visual concept is built around Guru Charan's AI-security and SOC identity.
